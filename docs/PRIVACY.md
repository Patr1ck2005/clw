# CLW 免费预览版隐私说明

版本：2026-10-17。

## 本机保存

每个安装保存自己的网页登录资料、对话工作记录、草稿、Goal、工具配置和执行回执。升级切换代码版本，不用旧数据覆盖当前任务；卸载默认保留数据，便于重新安装后继续使用。安装包不包含开发者的账号、登录资料、连接密钥、工作目录或历史任务。

首次连接填写的 Tunnel 运行密钥只在本机用于建立该连接，不作为模型提示词发送，不写入通用诊断。原生执行服务依其本机配置保存认证资料。请勿把整个数据目录作为安装包或普通反馈附件转发。

## 联网用途

原网页与登录由使用者自己的账号访问相应服务；工具连接访问使用者配置的 OpenAI Tunnel 和本地执行服务。配置的网络策略适用于本安装，不改写系统或 Edge 设置；指定代理不可用时不自行回退直连。

提交到网页的需求，以及模型读取或执行工具得到的内容，会按使用者所选账号、连接和任务发送给对应平台。平台对这些内容的处理由其隐私政策及使用者账号设置决定。

本版没有 CLW 云同步、默认遥测、广告、后台历史统计采集或自动上传诊断。查看保存在本机的记录和公式不需要额外平台查询。

随包 Bun 的自动崩溃报告和 PowerShell 的使用遥测在本安装的子进程中关闭，不改写系统环境变量。

## 诊断与反馈

“导出诊断”包含发行版本、组件状态、固定错误码及必要的连接时间线，默认不包含密钥、Cookie、聊天正文、提示词或项目文件内容。诊断由使用者手动保存和决定是否提供。

## 删除与卸载

卸载清理本安装拥有的程序、快捷方式和启动登记，默认保留数据。卸载说明会显示实际保留位置；需要删除账号或任务数据时，由使用者在确认不再需要后处理。CLW 不会清理用户的 Edge 资料或其他安装的数据。
