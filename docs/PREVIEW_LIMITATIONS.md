# CLW 免费预览版 · 已知范围

本版适合使用者自行试用；外部反馈另行收集。安装包未签名，SHA256 用于检查文件完整性。

- 安装最低要求为 Windows 10 1809（build 17763）x64，或 Windows 11 x64；这是随包 Bun 的[官方系统要求](https://bun.com/docs/installation)，安装器会拦截更旧系统。操作系统兼容门槛和实际干净环境测试分别记录。
- 核心运行环境随包提供；可选 Codex 路线仍需使用者自己的官方 CLI 和登录。
- Tunnel、ChatGPT 工作区关联和首次网页确认依照平台实际权限完成。CLW 不包含账号、模型额度或公共 MCP 中转服务。
- 本机后台连接可以在关闭界面后继续运行。修改网络不会强停已运行的后台或独立任务，后台网络变更在下次 Windows 启动时应用；设置页会保留待生效说明。
- 新增目录可热登记。移除目录目前保留为待后台安全重载，现有权限不会被设置保存动作立即收回。请在目录移除确已生效后再依赖该限制。
- 原网页的手动使用优先；附件、语音、下载、编辑和重新生成的完整增强体验不属于本版。
- 网页结构不能识别时，相应自动动作暂停，原网页仍可手动使用。网页、账号验证和平台服务可用性不能由本机安装测试替代。
- 不包含默认遥测、在线自动升级或后台用量历史查询。新版由使用者取得完整 EXE 后手动安装。

对应源码、安装测试、持续运行测试与待验项目分别记录在随发行提供的验收报告中。Windows 10 与 Windows 11 的干净系统检查未实际执行的项目会明确列为待验，不用开发电脑上的测试替代。
