## 给实际总控 M 的一次导出要求

> 请根据本对话实际掌握的材料，公开导出当前状态，而不是重建隐藏思考或补全未提供的信息。包含：原研究/开发目标；不可更改的假设、冻结 SHA 与权限；已决定事项及其依据；活跃参与者的职责、当前进展和实际证据引用；未决冲突与下一步建议。旧对话主张、当前推导、代数/代码验证、全波或实机证据、人工验收分开标注。缺失的进度或页面身份写“未知”，不要猜。只导出公开上下文，不启动新任务，不改他人文件。

直接保存用户复制或实际 M 导出的版本，传给 `harness_team_client.py import-context`。`source.kind` 仅 `user_copy` 或 `controller_public_export`；`reference` 是实际来源，不是模型编造的聊天 URL。导入后保留 hash 和原 JSON；participants 是状态描述，不会自动登记 Session、赋予写权或执行任务。

最小 JSON 形状如下（示例占位，不是当前项目事实）：

```json
{
  "name": "总控公开状态导出",
  "source": {"kind": "controller_public_export", "reference": "由原 M 提供的实际来源", "captured_at": "实际导出时间"},
  "objective": "原目标，保持原义",
  "constraints": ["当前负责人和冻结约束"],
  "decisions": ["已决定事项、证据级别及未解决问题"],
  "participants": [
    {"label": "A", "responsibility": "实际职责", "progress": "真实进展或未知", "references": []}
  ],
  "references": ["实际项目入口或证据相对路径"]
}
```

长内容总计不得超过90 KiB。单项文本上限见 CLI 校验；不能截断关键限制来凑大小，可引用现有完整文件并在导出中标明。分支工作只发其需要的完整工作块与证据引用，不反复复制全量总控聊天。
