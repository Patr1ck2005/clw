# CLW 免费预览版：安装与升级

本指南对应 Windows 10 1809（build 17763）及以后版本、Windows 11 x64 的免费、闭源、未签名 Setup EXE。首次使用见包内 README.md。安装包含核心运行环境，不含开发者的账号、登录、连接密钥、项目或历史任务。

## 正常安装

运行完整 Setup EXE，默认安装到当前用户的 LocalAppData / CLW Preview，不需要管理员权限。可以选择安装目录和桌面快捷方式。安装程序核对同一份冻结 payload、逐文件哈希及运行时合同后选择版本；安装结束不会自动发送模型消息或启动业务任务。

从开始菜单的 CLW Preview 或安装目录的 CLW.vbs 打开；CLW.cmd 保留为可见终端入口。首次设置包含网络、原网页登录、自己的 Tunnel 连接、工作目录。官方账号授权在对应网页完成，CLW 只初始化和管理本安装的本地执行环境。

应用和各后台进程显式使用随包 Python、PowerShell、Bun及原生程序；不改写系统 PATH 或已有 Codex 配置。可选 Codex 路线使用用户自己的官方 CLI 和登录。

## 升级与回退

先正常退出工作区，再运行新的 Setup EXE。安装器自动读取当前版本，完整安装候选后原子选择；失败时保留原数据和可用旧版本。不用旧备份覆盖当前任务库。

代码位于 versions/<build-id>/，任务、网页登录、连接和授权位于同一安装的 data/。回退切换代码，不回滚任务数据。当前版本和一个可回退版本保留；仍被原进程或连接清单引用的旧运行时延后清理。

初版不做在线自动更新。从开始菜单的 CLW Maintenance 或安装目录的 MAINTENANCE.cmd 查看并核验版本，或切回保留的上一版本。它调用现有 inspect / rollback 合同，不覆盖任务数据。未来不兼容的数据格式必须另有迁移方案，不能强制降级。

## 连接与退出

一个自带账号即可连接，第二个可选。登录 Windows 自动连接和手动恢复共用本安装的守候；网络等待不耗恢复次数。恢复不派发开发、计算或模型任务。

普通暂停仅停止后续自动发送。“停止网页生成”是独立动作。“退出并保留现场”等当前真实网页回合结束后退出，不因历史目标、旧错误或独立计算无限等待。未知发送、启动和 Job 均先核对原回执，不换键重放。

更新仅处理所选安装，不能关闭现有 Edge 或接管另一套 AB / Runner。运行中的独立 Job 保留；当前程序仍在使用时，显示具体占用并等待正常处理。

## 卸载与保留数据

Windows 应用列表中选择 CLW Preview 卸载。默认保留 data/，说明实际保存路径；重新安装到同一有效安装位置可找回数据。只清理本安装拥有的快捷方式、启动登记、已验证程序版本和运行时。在用版本或独立 Job 的运行文件保留并报告延后清理，不强杀进程。

## 发行身份和维护入口

_clw_web_release.json 记录本包实际源码文件、SHA256、组件和运行时合同。Git commit 标记来源，不能代替实际文件清单。Setup EXE 未签名；SHA256用于核对完整性，不是发布者身份认证。

免费使用条款见 FREE_PREVIEW_TERMS.md，隐私说明见 PRIVACY.md，第三方原许可见包内 NOTICE.md。内部验收与外部反馈分别记录，不能用源码测试代替另一个安装包的实测。

开发维护仍复用 scripts/web_workspace_release.py 的 prepare / install / select / inspect，以及 scripts/preview_installer.py 的安装、回退和保留数据卸载事务。不要手改 active.json、installation.json 或任务库来强制切换。
