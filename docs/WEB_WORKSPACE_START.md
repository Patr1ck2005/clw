适用 Windows 10 1809（build 17763）及以后版本、Windows 11 x64。CLW 自有代码采用 MIT License，预览版免费、未签名；模型账号、订阅和平台权限由使用者自己提供。

## 安装

取得完整 Setup EXE 和分发者提供的 SHA256，运行安装程序，按当前 Windows 用户安装。从开始菜单打开 CLW Preview。核心运行环境已经随包提供，无需先安装 Python、PowerShell 或 WebCodex Desktop。

Windows 可能显示未知发布者；这是本版未签名的实际状态。校验值用于核对完整性，不代表发布者数字签名。不需要修改系统 PATH 或关闭系统防护。

安装包内含第三方许可及对应源码材料。正常使用无需提取源码；需要时可在安装选项勾选，也可之后重新运行同一 EXE 提取。已知范围见 [预览版限制](docs/PREVIEW_LIMITATIONS.md)。

## 四步开始

1. **网络**：在“本机连接”选择跟随系统、指定代理或明确直连。指定代理不可用时不回退直连。首次连接前修改网络，按提示正常退出并重新打开；已经运行的独立后台保留原网络，新网络在下次 Windows 启动后统一应用，避免强停任务。
2. **登录**：打开账号网页，用自己的账号正常登录。原网页可直接输入、发送、停止和切换对话；没有本地工具时也能普通聊天。
3. **本地工具**：在 OpenAI Platform 的 Tunnel 设置创建或选择自己的 Tunnel，并关联目标 ChatGPT 工作区。把 Tunnel ID 和受限运行密钥填在本机设置中。随后在相同账号的 ChatGPT 中添加自定义 MCP 连接，选择同一 Tunnel；第一个账号名称使用 Local-MCP，第二账号可使用 Local-MCP-B。所需账号入口和权限以官方界面为准。
4. **工作目录**：明确选择允许本地工具使用的目录，保存并连接。在网页中让模型读取该目录的一个小文件，核对真实返回内容；“已连接”不代替实际工具检查。

一个账号就能使用。第二账号、Codex＋Web和自动协作都是可选项，不必先配置。Codex 入口使用自己的官方 CLI 和登录；缺少 CLI 不影响纯 Web。

新增工作目录可在现有连接中登记。移除目录时，已在运行的后台任务保留原权限；设置中的待生效说明消失后，才表示移除已经应用。

工具初始化、Tunnel 与网页账号分别建立，CLW 不替使用者创建平台账号或授权。密钥只填本机密码框，不要粘贴到聊天或反馈截图。正常连接步骤见 [OpenAI 官方说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)。

## 日常工作

直接使用原网页，或在工作区提交完整目标。手动输入、点击或切换网页时，后续自动发送让位于你的操作；单纯滚动不暂停。已送达回合和原工具执行继续，原消息回执不明时先核对，不重复发送。

普通对话回复后结束；开启 Goal 才自动接续未完成目标。工作期间的补充按原文和顺序排入下一轮。长计算保存原 Job 等结果，不用重复模型消息维持运行。

关闭窗口转入后台。“退出并保留现场”暂停后续发送，等当前真实网页回合结束后退出；旧 Goal、历史错误和独立 Job 不应造成无限等待。本地工具连接与独立 Job 保留自己的运行状态。

## 升级与卸载

运行新的 Setup EXE 升级，正常退出旧工作区后继续；不需要填写 build ID。升级保留当前数据及一个可回退版本，仍在使用的旧运行时保留。从“关于与诊断”核对版本和导出问题信息。

卸载默认保留本机账号、任务和配置，便于重新安装接续。数据位于所选安装目录的 data 文件夹；不要把这个目录当安装包转发。详细维护步骤见 [安装与升级](docs/WEB_WORKSPACE_CANDIDATE.md)。
