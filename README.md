# CLW 免费预览版

CLW 把网页聊天与自己的本地工具连接起来，保留手动网页使用，并提供任务记录、Goal 和长任务接续。软件免费，CLW 自有代码保持闭源。本仓库用于分发 Windows 安装包和使用说明。

从 [Releases](https://github.com/Patr1ck2005/clw/releases) 下载完整 Setup EXE；同时下载 `SHA256SUMS.txt` 和 `ACCEPTANCE.md`，核对文件与本次实际验证范围。安装包未签名，SHA256 用于检查完整性，不是发布者数字签名。

1. 运行安装包，按当前 Windows 用户安装。
2. 打开 CLW Preview，选择网络方式并登录自己的网页账号。
3. 如需本地工具，按引导配置自己的官方 Tunnel 连接和工作目录。
4. 先读取所选目录的一个小文件，确认实际返回内容，再开始工作。

只用一个账号即可；第二账号和 Codex 路线均可选。可以先跳过本地连接，直接使用网页聊天。各设备使用同一安装包，分别保存自己的账号、连接、目录和任务状态；本版不提供设备间云同步。

需要 Windows 10 1809（build 17763）或更新版本／Windows 11 x64，CPU 支持 AVX 和 AVX2。核心运行环境随包提供；可选 Codex 路线使用自己的官方 CLI 和登录。账号、订阅、平台权限和网络由使用者提供。

运行新版完整 EXE 即可升级。卸载默认保留本机数据，请勿把数据目录作为安装包或反馈附件转发。第三方许可随包保留，可重新运行同一安装包选择提取第三方源码材料。
