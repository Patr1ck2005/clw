怎样交给 Web 或 Codex？

结果未知或费用未知时怎么办？

保留原 Attempt 和回执引用，先在原执行端核对，再填写结果与依据。失败不等于免费。独立 API 按币种保存实际金额和本地预留，订阅不换算美元，也不自动复制进其他账本。
