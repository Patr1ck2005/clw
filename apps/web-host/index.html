如何手动使用
  1. 点击左侧「新建任务」，确认网页账号、模型和工作目录，打开 Codex＋Web 终端后直接输入完整目标。
  2. 在任务总览打开任务，查看工作记录或原对话网页。补充、停止和接续仍在原 Codex 终端操作，无需另一个 Codex 对话代管。
  3. 回合结束后核对结果；旧任务可以归档，归档不会删除对话。当前尚无自动唤醒桌面主控的完成通知。

Pro 用于完整工作包；流程测试使用 Extra High。纯 Web 的目标和补充直接在其工作记录中发送。

首次使用需要准备什么
需要已有 Python 3.11+、本机 Codex CLI 与 127.0.0.1:17890 的 VPN 代理。专用连接另需外部已创建的隧道标识、运行密钥文件和隧道客户端。保存后沿正常打开流程登录所选账号、核对连接器与真实工具。共享连接还需要原 Union、Local-MCP 后台、账号配置与授权；本页仅延续完整的现有共享配置，新安装不会复制开发环境的私有资料或另起轮询者。
