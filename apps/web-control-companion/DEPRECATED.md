# Deprecated split build

This directory is retained only for regression/reference while the unified carrier settles. User-facing installation is now `apps/web-recovery-companion/` (CLW Web Companion 0.2.0), which upgrades the previous Recovery Companion 0.1.1 path and combines original-request control with bounded generation-error recovery.

Do not install both extensions. Existing 0.1.1 users should reload the original `apps/web-recovery-companion/` unpacked extension in Edge.
